# ✨ Random Advice Generator

A simple and interactive **JavaScript API project** that fetches random advice from the **Advice Slip API** and displays it with a dynamic UI.

## 🧠 Features

- 📡 Fetch random advice from API
- ⚡ Built with **Async / Await**
- 🎨 Random background color change
- ⏳ Button loading state
- 📱 Fully responsive design
- 💡 Clean and minimal UI

---

## 🛠 Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- **Fetch API**

---

## 🌐 API Used

Advice Slip API
